# Savory House – Restaurant Website

A modern, responsive restaurant website built to showcase restaurant services, food menus and table reservations.

## Project Overview

Savory House is a restaurant website designed with an elegant interface, attractive food photography and a user-friendly layout. It allows visitors to explore the restaurant, browse its menu, view food galleries and submit table reservation requests.

## Features

- Modern and responsive homepage
- Restaurant introduction and about section
- Food menu with images, descriptions and prices
- Food gallery
- Interactive table reservation form
- Contact information and opening hours
- Responsive navigation
- Smooth scrolling and interactive elements

## Technologies Used

- HTML5
- CSS3
- JavaScript

## Getting Started

1. Clone or download this repository.
2. Open the project folder in Visual Studio Code.
3. Open `index.html` in your browser or use Live Server.
4. Explore the website and its features.

## Backend Status

The initial version is a front-end project. Reservation submissions are demonstrated through client-side interactions and are not yet stored in a database.

A backend and database integration can be added in a future version.
